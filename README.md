# 🧠 Neurovia

> Train Your Mind. Every Day.

## 📖 About

Neurovia is a brain training platform built using HTML, CSS, and JavaScript.

The goal of this project is to improve memory, focus, logic, reaction speed, and problem-solving skills through fun mini games.

This project is being built step by step with clean code, beginner-friendly explanations, and professional software development practices.
